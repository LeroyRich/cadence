Genre compatibility

Enabled by default. When on, the genre editor's upgrade permission is checked and locked. Turn this off to choose permission for each edit. The disk-write review shows every required upgrade.

Enabled by default. When disabled, Commit to disk starts the job directly from the proposed-changes review. The review and Cancel all changes confirmation remain enabled. Disk changes cannot be undone in Cadence.
